# Chapter 4: Query Optimization
=====================================

In this chapter, we will explore how indexing works in our database. Indexing is an optimization technique that improves query performance by providing quick access to specific data.

## Why Indexing?
---------------

Imagine you are searching for a book in a vast library. Without any help, it would take hours to find the desired book. But what if you have a librarian who can guide you directly to the book? That's basically how indexing works. It helps our database system to quickly locate specific data.

## Central Use Case: Finding Specific Data
------------------------------------------

Suppose we have a table called "customers" with columns "id", "name", and "email". We want to find all customers who live in New York. Without indexing, this query would take a long time because the database system needs to check every row in the table.

```sql
SELECT * FROM customers WHERE city = 'New York';
```

However, if we create an index on the "city" column, our query can quickly locate all customers who live in New York:

```sql
CREATE INDEX idx_city ON customers (city);
```

## How Indexing Works
---------------------

Here's a simplified explanation of how indexing works:

1.  **Index Creation**: We create an index on a specific column or set of columns.
2.  **Index Storage**: The index is stored in a separate data structure, usually on disk.
3.  **Query Processing**: When we execute a query that uses the indexed column(s), our database system can quickly locate the relevant rows by using the index.

## Indexing Types
-----------------

There are several types of indexes:

*   **B-tree Indexes**: These are the most commonly used type of index. They provide efficient lookup and insertion operations.
*   **Hash Indexes**: These use a hash function to map values to a specific location in memory. They can be faster for certain queries, but may not work well with range queries or equality searches.

## Example Use Case: Creating an Index
-----------------------------------------

Let's create an index on the "name" column of our "customers" table:

```sql
CREATE INDEX idx_name ON customers (name);
```

This will help us quickly locate all customers who have a specific name when we execute the following query:

```sql
SELECT * FROM customers WHERE name = 'John Doe';
```
