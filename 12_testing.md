## Introduction

Testing is an essential part of software development. It ensures that our code works as expected and provides valuable feedback to improve its quality.

In this chapter, we will learn how to write tests for a given use case. We'll break down the testing process into smaller, manageable chunks, making it easy for beginners to understand and implement.

## Use Case
------------

Let's say we have a simple calculator that takes two numbers as input and returns their sum.

```proto
message CalculatorInput {
  int32 num1 = 1;
  int32 num2 = 2;
}

message CalculatorOutput {
  int32 result = 0;
}
```

We want to write tests for this calculator. Our goal is to ensure that the calculator correctly calculates the sum of two numbers.

## Breaking Down Testing
-----------------------

### Step 1: Define Test Cases

We need to define test cases that cover all possible scenarios. In this case, we have two input values (num1 and num2) and one expected output value (result).

```proto
test CalculatorTest {
  CalculatorInput input = CalculatorInput(num1: 3, num2: 4);
  CalculatorOutput output = Calculator(input).output;
  assert(output.result == 7);
}
```

### Step 2: Write Test Code

We'll write test code using a testing framework. For this example, we'll use a simple Python-based testing framework.

```python
import unittest
from calculator import Calculator

class TestCalculator(unittest.TestCase):
    def test_addition(self):
        input = CalculatorInput(num1=3, num2=4)
        output = Calculator(input).output
        self.assertEqual(output.result, 7)

if __name__ == '__main__':
    unittest.main()
```

### Step 3: Run Tests

We'll run our tests to ensure they pass. If all tests pass, we're confident that our calculator works correctly.

```bash
python -m unittest test_calculator.py
```
